# Portfolio Architecte d'intérieur

Ce projet consiste à créer une page web dynamique pour le site d'une architecte d'intérieur.  
Le développement front-end utilise JavaScript pour gérer les interactions utilisateur, manipuler le DOM et communiquer avec une API back-end.

## 🎯 Objectifs du projet
- Développer une interface dynamique et interactive en JavaScript “from scratch”
- Gérer les événements utilisateur et manipuler le DOM
- Créer une page de connexion pour l’administrateur
- Implémenter une modale d’upload de médias
- Communiquer avec une API back-end pour récupérer et envoyer des données
- Respecter les maquettes fournies via Figma

## 🛠️ Technologies utilisées
- HTML5, CSS3
- JavaScript 
- API REST (back-end fourni pour tests)
- Figma (maquettes)
- Visual Studio Code (environnement de développement)
- Git / GitHub (gestion de version)

## 📂 Fonctionnalités principales
- Présentation dynamique des travaux de l’architecte via récupération des données API
- Page de connexion sécurisée pour l’administrateur
- Modale personnalisée permettant d’ajouter de nouveaux médias
- Gestion des erreurs et validations côté client
- Interface responsive adaptée aux différents écrans
